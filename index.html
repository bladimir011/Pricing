¿Cómo conectar el Google Sheet?
  1. Abrí tu Google Sheet.
  2. Compartir → "Cualquier persona con el enlace" como Lector.
  3. Pegá la URL o el ID arriba.
  4. Las primeras 3 columnas deben ser Producto, Código, Precio.
  5. Las columnas siguientes son rangos de precio (ej: 1-10, 11-50, 51+). El nombre de cada columna se usa como encabezado.
